CloudFolio Project Directory

Easy Navigation & File Directory

Everything is organized so you can navigate and edit files easily, even with 0% coding background.

🚀 How to Run CloudFolio with 1-Click

In Finder inside this CloudFolio folder, simply double-click on:

START-CLOUDFOLIO.command

It will automatically start your server and open http://localhost:3000 in your web browser! To stop it anytime, double-click STOP-CLOUDFOLIO.command.

📂 Simple Folder Guide

📁 1-WEBSITE-PAGES Front-End Pages

This folder contains all the visible screens and web pages of your application.

• page.tsx — The main public Landing Page (homepage) • portfolio/[username]/page.tsx — The candidate's live portfolio • dashboard/page.tsx — The student Studio Dashboard & Project Manager • login/page.tsx — The Sign-in page for students and recruiters • signup/page.tsx — The Handle claiming and registration page

📁 2-DESIGN-AND-BUTTONS UI Blocks

This folder contains visual building blocks, navigation bars, interactive features, and modals.

• Navbar.tsx — The top navigation bar with smart Sign In / Dashboard buttons • Footer.tsx — The sleek footer with links and monograms • FloatingTerminalButton.tsx — Expanding terminal logo button • DeveloperTerminal.tsx — The retro-modern interactive terminal shell • PortfolioSettingsSection.tsx — Unified feature toggles & access control settings • StoryModeModal.tsx — 60-Second high-speed recruiter story mode • InteractiveArchitectureDiagram.tsx — System design traffic simulator • LandmarkPRViewer.tsx — Git milestone PRs and code diff viewer • ResumePDFModal.tsx — 1-Click ATS resume generator and previewer

📁 3-STUDENT-DATABASE Database JSON

Where student accounts, project details, settings, and recruiter messages are saved.

• students.json — The database storing student profiles (projects, GPA, settings, bio)

📁 4-LOGOS-AND-IMAGES Media Assets

Contains your application logos, favicons, and graphic assets.

• logo.png — CloudFolio official brand logo • favicon.ico — Browser tab icon

📁 5-CORE-LOGIC-AND-TYPES Data Models

Under-the-hood logic connecting the front-end to the database.

• types.ts — Data definitions for Students, Projects, and Settings • mock-data.ts — Default seed profile for Alex Chen • api-client.ts — Front-end helper making HTTP requests to API • server-db.ts — File-system database driver for Next.js API
